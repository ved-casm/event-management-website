# Sanskriti Events & Planners

Four-page Next.js design preview: Home, Our story, Gallery and Connect.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

```sh
npm test -- --runInBand
npm run build
npm start
```

## Preview limitations

- Indexing is disabled intentionally. Set final production metadata and indexing rules only when launching on the approved domain.
- The inquiry form uses FormSubmit. Production delivery requires recipient email activation and an inbox test. See CONTACT-FORM-SETUP.md.
- Images are stock inspiration, not a claim that Sanskriti delivered the pictured events. Credits are in IMAGE-CREDITS.json.
- The supplied text containing സംസ്കൃതി7 has not been silently corrected.
- Instagram and Facebook profile URLs still need confirmation. WhatsApp +919048704545 is confirmed and linked in About/Connect with an editable draft, never an automatic send. The highlighted call link preserves supplied local digits.
- The original supplied logo's dimensional artwork is retained. A separate transparent version removes the surrounding matte without redrawing it.
- Respect reduced motion. Lenis and the parallax effect are disabled when that preference is active.
